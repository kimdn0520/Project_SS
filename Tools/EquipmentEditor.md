# 장비 콘텐츠 관리

Unity 상단 `ProjectSS > 콘텐츠 관리`에서 엽니다.

- 상단 메뉴: 장비 / 캐릭터 / 몬스터 / 스킬 / 스테이지 / 상점. 장비·스킬 외 메뉴는 확장용 자리입니다.
- 기본 카탈로그: `Assets/Prototype/ExpeditionCatalog.asset`. 다른 카탈로그 에셋도 선택할 수 있습니다.
- 왼쪽에서 이름·ID·설명 검색, 희귀도·부위 필터, 장비 선택, 새 장비 생성, 복제를 지원합니다.
- 오른쪽에서 이름, 아이콘, 사용 직업, 일반·희귀·영웅·전설·신화, 기본 능력치, 고유 효과, 옵션 후보, 스킬, 제작 비용을 설정합니다.
- 편집본은 원본과 분리됩니다. `전체 저장` 또는 `Ctrl+S`로 편집한 장비와 스킬을 모두 저장하고 `전체 되돌리기`로 미저장 편집을 버립니다. 실행 취소·다시 실행과 창 닫기 시 저장 확인을 지원합니다. 스킬을 여러 개 오가도 각각의 편집본은 유지됩니다.
- 저장 전에 전체 장비를 검증합니다. 중복 ID, 잘못된 수치 범위, 유효하지 않은 스킬 설정은 저장되지 않습니다. 외부에서 원본이 변경되면 덮어쓰기를 막습니다.

## 옵션과 스킬

초반 랜덤 옵션은 최대 1개를 기본값으로 둡니다. 후보 목록은 추첨 대상이고 가중치는 상대 확률입니다. 같은 종류의 후보는 중복할 수 없습니다. 후보가 없거나 최대 개수가 0이면 옵션을 사용하지 않습니다. 최대 개수는 추후 확장할 수 있습니다.

고유 효과는 기존 장비의 고정 특성입니다. 전설·신화는 스킬 라이브러리에서 저장한 스킬 에셋 1개를 선택합니다. 낮은 희귀도로 변경해도 연결은 자동으로 지우지 않으며, `연결 해제` 후 저장할 수 있습니다.

### 스킬 만들기와 연결

1. **스킬 탭 → 새 스킬**에서 이름·아이콘·설명·효과·발동 조건·쿨타임 등을 설정합니다. `선택 복제`는 독립된 스킬과 새 ID를 만듭니다.
2. **전체 저장**으로 스킬 에셋을 `Assets/Prototype/Skills`에 저장합니다.
3. **장비 탭 → 전설 또는 신화 → 장비 스킬**에서 저장한 스킬을 선택합니다. 에셋 필드의 검색창이나 라이브러리 목록을 사용할 수 있습니다.
4. 미리보기로 내용을 확인한 뒤 **전체 저장**합니다. `스킬 탭에서 편집`으로 원본 스킬 편집본을 열 수 있습니다.

여러 장비가 같은 스킬을 참조합니다. 스킬을 수정해 저장하면 연결된 모든 장비에 반영됩니다. 장비를 복제할 때에도 스킬은 같은 에셋을 참조하며, 별개의 스킬이 필요하면 스킬 탭에서 먼저 복제하세요. 스킬 탭의 `연결된 장비` 목록은 현재 장비 편집본의 미저장 연결도 반영합니다.

기존 인라인 스킬 설정은 삭제하지 않고 보존합니다. 장비의 `기존 설정을 스킬 에셋으로 저장·연결` 버튼으로 별도 에셋을 즉시 생성하고 편집본에 연결할 수 있습니다. 같은 ID의 다른 스킬은 덮어쓰지 않고 새 ID를 부여합니다. 이후 장비 연결도 `전체 저장`해야 합니다. 이관 및 장비 예시 버튼으로 이미 생성한 스킬 에셋은 장비 편집을 되돌려도 라이브러리에 남습니다.

`전설 서리지팡이 예시` 버튼은 편집본 끝에 예시를 추가하고 공용 `서리 폭풍` 에셋을 연결합니다(동일한 스킬이 없으면 생성). 예시 수치는 공격력 35, 최대 옵션 1개, 공격력 3~8% 후보, 10초마다 반경 3 내 적을 2초 빙결하는 스킬입니다. 밸런스 확정값은 아닙니다.

## 게임 연결 범위

기존 공격력·체력·공격 간격·고유 효과 필드를 그대로 편집합니다. 새 희귀도·랜덤 옵션·스킬은 작성 및 저장 데이터이며, 실제 옵션 추첨과 광역 스킬 발동은 후속 전투 시스템 구현이 필요합니다.

기존 세이브가 장비 배열 인덱스를 사용하므로 삭제·순서 변경 기능은 제공하지 않습니다. 장비 추가 시 기존 세이브의 보유 수량 배열을 0으로 확장해 진행을 유지합니다. 새 장비의 게임 표시에는 기존 고정 인벤토리 UI, 캐릭터 파츠, 드롭 프리팹을 연결해야 합니다. 기존 UI의 사전 작성된 장비 설명도 자동 재생성 범위에 포함되지 않습니다.

## 확장 및 검증

`IContentManagementPanel` 구현을 `ContentManagementWindow.OnEnable`의 패널 목록에 등록하면 메뉴를 확장할 수 있습니다. `GearAuthoring.cs`는 런타임에서 읽을 데이터만 포함하며 에디터 UI는 `Assets/Editor`에 분리되어 있습니다.

`SkillDefinition`은 공유 스킬 에셋입니다. 장비의 `skillAsset`이 이를 참조하며, 런타임은 `GearDefinition.ResolvedSkill`로 설정을 조회할 수 있습니다. 전설 미만은 null, 전설 이상은 연결된 공용 설정을 반환합니다. 이관 전에는 활성화된 기존 인라인 설정을 반환합니다. 공유 설정 안의 `enabled`는 이전 저장 형식 호환용이며 새 공유 스킬의 활성화 여부로 사용하지 않습니다.

Unity `execute_script`로 `Tools/EquipmentEditorQA.cs`의 `Execute`를 호출하면 임시 카탈로그에서 저장·재로드·복제·검증·Undo/Redo·세이브 확장을 확인하고 임시 에셋을 제거합니다. 결과는 `PrototypeQA/equipment-editor-checks.txt`에 저장됩니다.

`Tools/SkillEditorQA.cs`의 `Execute`는 스킬 생성·다중 편집·공용 참조·설정 이관·ID 충돌·외부 변경 감지·Undo/Redo를 확인합니다. 결과는 `PrototypeQA/skill-editor-checks.txt`에 저장됩니다. 실제 전투 발동을 검증하는 테스트는 아닙니다.
